04 / EVERY WORD HAS A WITNESS

Read the denominator.

Distinct content tokens

Containment is matched distinct tokens / all distinct claim tokens, in one document. Repetition does not add weight. Stopwords are removed. Sources are never combined into a synthetic supporting passage. Ties choose the first eligible source.

Citation markers and answer offsets

This audit uses the historical punctuation/newline splitter, with decimal points masked. Put a marker before terminal punctuation: "Claim [1]." A marker after a period belongs to the next unit, or a separate no-content unit. This convention is not a universal citation parser. The exported original all-source report strips markers before splitting, so its unit count can differ.

05 / EQUAL NUMBERS, UNEQUAL CLAIMS

A match is a location, not a reason.

Equality uses the complete decimal value: 1.570 equals 1.57 and -0.00 equals 0. Integers beyond 2^53 do not collapse together, and long finite numbers do not match just because both overflow a float. Units, entities and relations are not checked.

06 / CONTROLS AND LIMITS

The failure cases stay visible.

The same 43-test claim with [1] versus [2] can pass globally while losing its evidence in cited-only scope. Negating that claim can still pass cited lexical containment. A true paraphrase can fail it. These are controlled synthetic examples, not an accuracy estimate or proof that one policy is better.

The original default check still searches all documents. Three fixes are explicit: exact decimal comparison replaces binary64 number equality; terminal punctuation no longer hides a final number while dotted versions remain excluded; full-precision support reaches gates before display rounding. Nonfinite and out-of-range thresholds are rejected.

The audit is bounded to 8 sources, 4,096 ASCII characters per text, 64 units, 128 total numeric occurrences and six-digit citation positions. All occurrences and source scores are exported, not truncated. ASCII is an explicit cross-runtime profile, not a multilingual support claim. The original check retains its historical Unicode behavior. Commas are still stripped even in malformed literals, scientific notation is not recognized as one number, and the tokenizer is not a linguistic parser.
